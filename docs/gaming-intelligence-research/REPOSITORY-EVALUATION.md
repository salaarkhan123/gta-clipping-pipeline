# Candidate repositories, models and weights

Evidence checked 2026-11-19. The first comparisons worth funding are a fixed-region scoreboard reader, a lightweight audio tagger and a missing-game router. A frame detector improves on a scoreboard reader only if it recovers a material number of otherwise missed events. A model that identifies an event still needs to beat the current ranker on entertaining clips.

Numbers below come from the linked publishers' evaluations. Each number belongs to its stated task and artifact. None measures ClutchClips accuracy, server latency or cost. Scores across COCO detection, MOT tracking, AudioSet tagging, OCR and video retrieval cannot rank highlight quality. “Unmeasured” means a comparable deployment measurement was unavailable or was not reproduced. Integration and cost classes are engineering estimates.

## Choosing a deployment experiment

Start each model in an isolated offline environment with a pinned source revision, SHA-256 of downloaded weights, archived license text, runtime/codec versions and the list of artifacts it downloads transitively. For score and event comparisons, fix the exact input crops and timestamps. Evaluate title accuracy, event precision and boundary error before asking whether any of them improve top-K highlights. Uncertain rights hold that candidate; other candidates can proceed.

Use the cost of the incremental work. On one worker, billed worker-hours per video-hour times the worker rate includes busy and idle time, plus storage, transfers and any per-call or per-license charge. Attribute exclusive kernel/CPU time by stage to explain differences while avoiding double-counting shared decode or concurrent execution. At one frame per second, a whole-hour pass touches 3,600 frames. A candidate-only pass covering 10% of the hour at 4 fps touches 1,440 frames before overlapping windows are coalesced. A 2.3 ms kernel benchmark applied to 3,600 frames yields only 8.28 s of kernel arithmetic and excludes seeking, memory copies, setup, queues and other stages. The workload and billing gates are defined in [GPU requirements](GPU-REQUIREMENTS.md) and [evaluation](EVALUATION-FRAMEWORK.md).

Treat engagement prediction separately from physical event recognition. A pretrained object or clip retrieval score cannot account for distribution, creator reach or publication age. Compare an interpretable matched-cohort model with content-only and context-only baselines on rights-cleared outcomes, and test held-out creators and publication periods before rewarding any predicted engagement. See [virality research](VIRALITY-RESEARCH.md).
