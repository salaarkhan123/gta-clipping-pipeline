## Decision points

After Phase 1, choose the signal with the strongest *incremental* event recall at acceptable precision and measured cost. If neither named sound nor HUD text passes, invest in annotation, state attribution or transcript boundaries according to the error review. Do not buy a GPU to remedy label uncertainty. After Phase 2, advance individually qualifying profiles. Fortnite, CoD/Warzone, CS2, Apex, Minecraft, LoL and Siege each need a distinct profile, rights-cleared examples, a measured false-positive budget and a regression fixture before enabling any title-specific feature. [Per-title tests](GAME-SPECIFIC-DETECTORS.md)

Production enablement would be a separate review after 3A. Keep feature flags per class/profile, default zero, an immediate baseline fallback and a reproducible previous weights hash. A release review must see: number of eligible clips, successful and failed jobs, paired ranking gains, worst supported subgroup, p95 extra wall time, VRAM and total dollars per source hour. A change that meets a class threshold but yields no end-to-end gain stays in the research runner.
